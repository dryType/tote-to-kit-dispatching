# AI usage disclosure

This project (Tote-Kit Dispatch Trace, Information Visualization term project) used a generative AI coding assistant
(Claude Code, model Claude Opus 5.5, Anthropic) on 2026-10-26. The table lists every file the assistant created or
modified, and what it did. Files not listed were written by the author. The discrete-event simulator and the
dispatching policies (`src/simulation_engine/simulator.py`, `processes.py`, `entities.py`, `src/policy/`) were not
modified by the assistant.
