요청한 세 가지를 하나의 파이프라인으로 실행했다 (약 62분). **모든 변경은 커밋하지 않았다.**
1. U3 검증과 연속형 c_x(ρ)
2. 원형 ATC 비교군

## 요약

| 항목 | 결과 |
|---|---|
| **U3 검증** (ρ(t) > 0.8이면 보관 토트 벌점 끔) | 같은 c_x에서 벌점을 항상 켠 버전 대비 medium 총 지연이 **약 45% 감소**했다 (58,383 → 31,674초). 효율·잔량은 거의 같았다 (잔량 55.1 → 55.8). 설계 인스턴스의 결과가 검증 seed에서도 유지됐다 |
| **연속형 c_x(ρ)** | 설계 그리드에서 c_x = 4, ρ 0.6–0.8을 골랐다. 검증 결과는 U3(켜기/끄기)와 거의 같아서(총 지연 31,279초 대 32,089초) **추가 이득은 없었다** |
| **원형 ATC 비교군** | 키트 단위 ATC + 최대 충족(κ = 2)은 **Greedy와 사실상 같았다** (medium 실패 25 대 27, 효율 지표도 거의 같음). 이득은 키트 순서가 아니라 후보 단위의 효율 점수에서 나온다는 뜻이다 |
| **large** | 새 CPR U3가 총 지연이 가장 적었다 (7,071초). 기존 CPR은 부하 1.0에서 크게 무너졌다 (84,101초) |
| **교란** | 모든 정책이 나빠졌지만 순위는 결정적 환경과 같았다. ATC형 > 새 CPR (U3·연속형) > 새 CPR v1 > 기존 CPR > 원형 ATC ≈ Greedy |

**잠정 결론**: 새 CPR U3(c = 1, c_x = 2, ρ > 0.8이면 보관 토트 벌점 끔)는 잘 튜닝한 기존 CPR (0.8, 0.1, 0.1)보다 모든 지표에서 같거나 낫다 (medium 검증 기준). 다만 ATC형(보관 토트 항 없음)과는 여전히 **지연 대 잔량**의 맞교환 관계다.

| 정책 | 결정적 (30개) 실패 / 총 지연 | cv 0.2 실패 / 총 지연 | cv 0.4 실패 / 총 지연 |
|---|---|---|---|

| 원형 ATC | 15 / 22,449 | 32 / 46,739 | 37 / 66,427 |
| 기존 CPR | 11 / 18,428 | 27 / 42,885 | 29 / 59,472 |
| ATC형 | **8 / 5,456** | **19 / 13,110** | **20 / 24,473** |
| 새 CPR v1 | 11 / 12,554 | 21 / 24,964 | 26 / 40,331 |
| 새 CPR U3 | 10 / 8,022 | 22 / 18,172 | 27 / 25,746 |
| 새 CPR 연속형 | 11 / 7,446 | 22 / 17,845 | 29 / 25,479 |

- 결정적 환경은 인스턴스 30개, 교란 환경은 60단위(인스턴스 × 교란 seed 2개)라서 실패 수를 직접 비교하면 안 된다. 실패율로 보면 다음과 같다.
  - ATC형: 27% → 32% → 33%
  - 새 CPR U3: 33% → 37% → 45%
  - 기존 CPR: 37% → 45% → 48%
  - Greedy: 57% → 60% → 63%
- 효율(핵심 5개 정책이 모두 지연 0인 단위의 평균)도 결정적 환경과 같은 경향이었다. cv 0.2에서 잔량 토트는 새 CPR 연속형 54.0, U3 56.8, 기존 CPR 62.6, ATC형 92.6이었다.
- **"사전 계획을 그대로 실행"하는 비교군은 아직 없다.** 실시간 정책의 필요성을 보이려면 이 비교군이 있어야 한다.

## 해석과 한계

1. **U3는 검증 seed에서도 효과가 유지됐다.** 단계 b(상태에 따라 가중치 조정)의 첫 근거가 된다. 연속형은 켜기/끄기 버전보다 나은 점이 없었으니, 지금은 단순한 U3로 충분하다.
2. **ATC형과 새 CPR U3는 지연 대 잔량의 맞교환이다.** medium에서 실패는 16 대 19, 총 지연은 27,724 대 31,674초이고, 잔량은 92.6 대 54.9다. 어느 쪽을 택할지는 잔량 토트 비용(환산 단위, 보류 중)에 달려 있다.
3. **문헌 ATC를 키트 단위로만 적용하면 Greedy와 같다.** 계획서에 쓴 "ATC 계열 비교군"을 이 형태로 쓰면 약한 비교군이 된다. 논문에서는 "키트 단위 ATC"와 "후보 단위 효율 점수(본 연구)"를 구분해서 설명해야 한다.
4. **한계**
   - 설계용 seed 4개, 검증 seed 10개, large 9개, 교란 seed 2개 규모다.
   - U3 임계값(0.8)과 연속형 범위는 설계 인스턴스(부하 0.8–0.9)에서 골랐다.
   - ATC형은 κ = 8, 새 CPR은 κ = 32인데, κ는 이전 실험에서 결과에 거의 영향이 없었다.
   - ρ(t)를 쓰는 정책은 결정마다 잔여 부하를 다시 계산해서 1회 실행이 약 2배 느리다 (medium 단독 약 16초).
